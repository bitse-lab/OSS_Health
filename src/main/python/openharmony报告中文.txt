- Key Metric Interpretation (What–Why–How Analysis)
Metric: monthcommit（社区活跃度）
What: 2024 延续高位（约 2.4k–3.6k），2025 多数月份 2.3k–3.6k，年初约 1.86k 小幅低位，年末回到 4.0k+；2026-01 为 4.62k、2026-02 为 2.24k，活跃度总体强劲。

How: 维持节奏管理（版本里程碑、冻结窗口），平衡大批量合并与持续集成压力；对低位月份提前规划 code freeze/发布窗，避免突发堆积。

Metric: monthpr（社区产出/协作）
What: 2024 多月约 1.3k–2.0k；2025 大多在 1.1k–1.8k，存在个别低值（2025-05 为 999），9 月达 2.0k+；2026-02 为 1.51k，保持中高位。
Why: PR 数与提交节奏相呼应；个别低值可能与短月、发布冻结或集中合并后短暂回落有关。
How: 继续优化 PR 模板与自动检查，减少低价值切分；对冲刺期设置评审人轮值，确保吞吐稳定。

Metric: monthissue（问题与需求输入）
What: 2024 多在约 0.8k–1.7k、年均约 1.4k；2025 回落至约 0.7k–1.4k；2026-01 为 1437、2026-02 为 1010，整体稳定。
Why: 输入量与用户基数、发布期反馈高峰相关；2025 年回落可能是稳定期/技术债清理期所致。
How: 持续执行 issue 模板与分类标签；结合里程碑做批量 triage，保障响应与关闭效率，避免堆积。

Metric: reviewratio（评审覆盖率）
What: 长期接近 1；2025-09 至 2025-12 下探至约 0.92–0.98 区间后，2026-02 回升至 0.958，恢复势头明确。
Why: 阶段性下探可能源于评审人负载或 PR 峰值导致的评审延迟。
How: 建立评审 SLA 与提醒机制，配置“值班评审官”；统计长时间未评审 PR，自动升级或重分配，稳住 0.96+。

Metric: prmergedratio（PR 合并率）
What: 2024–2025 大多在 0.64–0.71；2026-02 为 0.636 略低于下沿，整体处于中高位。
Why: 合并率受 PR 质量、冲突/CI 失败与评审严格度影响；略低可能来自临近版本的质量把关或大量试探性 PR。
How: 强化“先本地/沙盒 CI 再提交”、预检查清单与合并准入标准；对重复/低质量 PR 做贡献指南回访，稳步抬升下沿至 0.66+。

风险与关注：

- prlinkedissue 仍偏低，追溯性与可治理性有提升空间。

- 关联度提升：在 CI 强制校验 PR 需关联 issue（或标注合理豁免），季度复盘未关联成因，迭代模板与流程。
